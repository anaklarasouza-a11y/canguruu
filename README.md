<br>

**A)** Sydney  
**B)** Melbourne  
**C)** Camberra

## 💡 3 Curiosidades Rápidas que Você Precisa Saber

1. **A Grande Barreira de Corais** é o maior organismo vivo do mundo e pode ser vista do espaço! 🪐
2. **Neve na Austrália:** Os Alpes Australianos recebem mais neve durante o inverno do que a Suíça! ❄️
3. **Praia para cada dia:** A Austrália tem mais de 10.000 praias. Se você visitasse uma nova praia por dia, levaria mais de **27 anos** para ver todas! 🏖️
